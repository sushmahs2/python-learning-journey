## ▶️ Getting Started

Clone the repository:

```bash
git clone https://github.com/sushmahs2/python-learning-journey.git
```

Navigate to the project:

```bash
cd python-learning-journey
```

Run the Day 1 program:

```bash
python day-01/day1_arithmetic.py
```

On Windows, you can also use:

```powershell
py day-01/day1_arithmetic.py
```
